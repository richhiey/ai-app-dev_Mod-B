# Optional Lovable mock exploration

This optional activity lets you try one interface idea before continuing with the required Streamlit app. Use a personal free account only if available; a sketch is an equal alternative. Do not buy credits.

For the full optional activity, use the [personal free-account guide](../../docs/lovable-student-guide.md).

1. Review [`first-build-prompt.txt`](first-build-prompt.txt) and build one mock chat screen, or sketch it.
2. Try the prompt's three mock cases in the preview. Check whether turns stay ordered and a new error starts without old sources.
3. Record a design choice, one behavior to check in Streamlit, and one limit of the mock in [`review-notes-template.md`](review-notes-template.md).

The mock does not call FieldCare or a model. Do not configure a backend, export code, publish the app or enter credentials. You may skip this activity; it supplies no required project artifact.
