# Optional Lovable mock exploration

Sprint 4's required UI is the Streamlit app. This guide supports an optional, short mock-design activity; it does not describe the FieldCare integration.

If you want to try Lovable, use a personal free account and check the available allowance first. Do not purchase credits. You may skip the tool and sketch the same screen.

1. Open the [`examples/lovable/first-build-prompt.txt`](../examples/lovable/first-build-prompt.txt) and review its scope before using it.
2. Build one mock chat screen, or sketch it. Try the success, clarification and deliberate-error cases described in the prompt.
3. Record one design choice, one behavior to check in Streamlit, and one limitation of the mock with the [`optional notes template`](../examples/lovable/review-notes-template.md).

The mock uses fixed replies. It does not call FieldCare or OpenRouter and does not prove the service works. Do not set up a database, add credentials, export code or publish the prototype. Continue the required project in Streamlit, using the [Streamlit teaching kit](../examples/streamlit/README.md).
