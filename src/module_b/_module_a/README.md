# FieldCare evaluation examples

This package contains a reference evaluation implementation and synthetic cases for comparing FieldCare pipeline designs. It is separate from the FastAPI service in `service/fieldcare/`.

The evaluation assets are bundled locally, so the evaluation does not need a second repository or a remote data source. To explore them, start with [`data/README.md`](data/README.md), then use the commands in [`clients/README.md`](../../../clients/README.md).
