## Campus project path

The Campus work extends the local FieldCare project built in Sprints 1–3:

1. In Lovable, shape and review the companion UI with a mock response. Keep the built-in Lovable Cloud backend, which is Supabase-based; do not connect a separate Supabase project.
2. Sync the UI to its own GitHub repository, then run that UI and FieldCare locally.
3. Connect the UI to the local service through the checked-in TanStack Start route.
4. Test a real request and match its request ID to the safe FieldCare record, then document the service and UI for a teammate.

Follow the [Lovable student guide](../../docs/lovable-student-guide.md), [integration example](../../examples/lovable/README.md), and Sprint 4 Campus lessons for the local workflow. The notebook linked above belongs to the separate Live workshop.
